# 煎饼侠点餐系统 Demo

这是一个无需后端的 HTML 演示版，适合部署到 GitHub Pages 给店主体验。

## GitHub Pages 部署

1. 登录 GitHub，新建一个仓库，例如 `jianbing-demo`。
2. 进入仓库，点击 **Add file > Upload files**。
3. 上传本目录的全部文件，确认根目录中直接包含 `index.html`、`煎饼侠-点餐.html`、`煎饼侠-商家订单管理.html`。
4. 点击 **Commit changes**。
5. 打开仓库的 **Settings > Pages**。
6. 在 **Build and deployment** 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。
7. 等待约 1 分钟，在 Pages 页面打开生成的网址。网址通常是：

   `https://你的用户名.github.io/仓库名/`

店主直接打开这个网址即可看到入口页。

## 演示流程

1. 打开入口页，进入“顾客端点餐”。
2. 选择商品，填写地址、姓名和手机号，点击“提交订单并支付”。
3. 在支付弹窗点击“确认支付”。这是演示支付，不会真实扣款。
4. 建议在同一个浏览器中打开另一个标签页，进入“商家端”。
5. 输入演示密码 `8888`，即可看到顾客刚提交的订单。
6. 商家点击“标记完成”，顾客端的“我的订单”会同步显示“已完成”。

## 重要说明

- 当前版本使用浏览器 `localStorage` 保存订单，只适合演示，不是真实线上系统。
- 顾客端和商家端要使用同一个浏览器、同一个浏览器用户配置，才能共享演示订单。
- 顾客标识也保存在当前浏览器中，所以清除浏览器站点数据后会变成新的演示顾客。
- GitHub Pages 只能托管静态页面，不能提供真正的订单后端、管理员安全认证或微信支付。
- 正式交付时需要迁移到微信小程序云开发，并接入真实商户号和微信支付。
